# Public Project Dossier

The downloadable [Public Project Dossier PDF](../public/documents/tiny-custom-stories-project-dossier.pdf) is a visually reviewed 15-page public explanation of Tiny Custom Stories and a fixed-layout companion to the responsive website.

## Public scope

The dossier may cover product direction, accepted decisions, open questions, logical architecture principles, proposed workflow responsibilities, demonstrated Sprint 0 evidence, the active Sprint 1 family-mode boundary, outcome-gated delivery intent, design philosophy, and the reproducible visual recipe. It preserves the difference between a confirmed decision, verified fact, proposal, assumption, and open question.

## Exclusions

The dossier must not include credentials, secrets, private URLs, internal board or issue detail, private research, personal information, family or child data, exact data schemas, detailed threat analysis, operational configuration, or unpublished code.

## Maintenance

The founder reviews material public changes. A future revision must preserve knowledge-status labels, run a public-safety review, regenerate the document through `scripts/generate_project_story_pdf.py`, render and visually inspect every PDF page, and arrive through the public repository's protected pull-request workflow. The website remains the primary version for semantic navigation and text reflow.
