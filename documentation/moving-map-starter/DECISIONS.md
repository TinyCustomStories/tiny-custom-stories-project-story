# Moving Map — accepted decisions

Only **accepted** decisions and supersessions are authoritative here. Keep unapproved proposals in the relevant existing discussion or PR.

## Example decision format

### DEC-001: [Brief title]

- **Status:** Proposed / Accepted / Rejected / Superseded
- **Date and decision owner:** [Date, authorized decision-maker]
- **Discovery and evidence:** [References to code, usage, test, design or user research]
- **Decision:** [Precise accepted behavior or contract]
- **Affected owners/contracts:** [Only relevant dependencies]
- **Reversibility:** [Compatibility and rollback plan]
- **Review:** [Independent reviewer and evidence, if applicable]
- **Supersedes:** [Previous decision if applicable]

Do not mark a proposal Accepted just because several agents prefer it. Recheck accepted decisions before integrating work that depends on them.
