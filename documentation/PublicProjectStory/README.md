# Public Project Story documentation

This directory explains the public Tiny Custom Stories project-story site in a format that can be read without opening the application.

The public site is a multi-route single-page application. A route is a stable browser address that presents one topic at a time while the application remains loaded. This keeps the public story navigable and gives each subject enough room for definitions, context, and source-aware status labels.

## What is documented here

- [Wireframes](Wireframes.md) describe the information architecture and intended responsive layouts in accessible text diagrams.
- [Screenshot evidence](ScreenshotEvidence.md) records reviewed visual states and the conditions under which they were captured.
- The [Public Project Dossier](../../public/documents/tiny-custom-stories-project-dossier.pdf) is a portable 15-page companion. It expands the same public-safe material but does not replace the website's semantic, responsive version.

These documents describe the public-information experience only. They do not specify the future parent/child product, adopt policy, or expose private working materials.

The interface applies the accepted public design language: a calm editorial foundation, limited handcrafted character, purposeful emphasis, visible knowledge status, complete interaction states, accessibility, and responsive recomposition.

## Vocabulary

- **Public project story**: A founder-reviewed explanation of the project for a general audience.
- **Knowledge status**: A label that states whether a public entry is a confirmed decision, verified fact, proposal, assumption, or open question.
- **Wireframe**: A low-detail layout description that explains hierarchy and navigation without claiming final visual design.
- **Screenshot evidence**: An image of a reviewed implementation state, captured with synthetic content and checked for private or child/family information.
- **Fragment route**: A page address such as `/#/decisions`. The browser keeps the static GitHub Pages document path while the application presents the requested page.
- **Portable companion**: A downloadable fixed-layout PDF generated from reviewed public-safe copy. It supports the website rather than replacing its accessible structure.

## Maintenance rule

When a public-site route, hierarchy, or responsive behavior changes, update the relevant wireframe and capture a new reviewed screenshot when the visual change is material. Screenshots are explanatory documentation assets, not automated pixel-comparison baselines.
