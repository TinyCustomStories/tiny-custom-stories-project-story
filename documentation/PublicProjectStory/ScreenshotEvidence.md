## Capture method

1. Run the independently buildable Vite application locally.
2. Open the named route at the stated viewport.
3. Confirm the browser shows no private material, personal data, secrets, or error state.
4. Capture the visible page and inspect the resulting image.
5. Update this table, the relevant wireframe, and the asset only when a material visual or information-architecture change has been reviewed.

These files are documentation references. They are deliberately not used as automated visual-regression snapshots.
